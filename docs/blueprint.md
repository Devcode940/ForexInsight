# **App Name**: ForexInsight AI

## Core Features:

- Live Analysis Charts: Interactive candlestick charts using TradingView Lightweight Charts for major currency pairs including EURUSD, GBPUSD, and USDJPY.
- Smart Timeframe Control: Switch between standard trading timeframes from 1m for scalping to Daily for long-term trend analysis.
- Pattern Recognition Engine: A tool that uses generative logic to automatically detect and highlight candlestick patterns like Hammers, Engulfing, and Dojis.
- Explainable Trade Signals: Generate clear Entry/Exit signals accompanied by plain English AI-powered tool explanations for the logic behind the trade.
- Technical Indicator Suite: User-controlled toggles for professional indicators including SMA, EMA, RSI, MACD, and Bollinger Bands.
- Dynamic Side Watchlist: A persistent sidebar allowing users to track multiple pairs and their current market sentiment at a glance.
- Interactive Fibonacci Tool: Drawing layer for Fibonacci retracement levels to identify potential support and resistance zones.

## Style Guidelines:

- Dark mode primary scheme: A tech-focused deep navy background (#111519) with a vibrant electric blue primary (#3A86FF) for indicators and data points.
- Accent colors: Analogous cyan (#4CC9F0) for tooltips and signal highlights, providing sharp contrast against the dark background.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact technical headers and 'Inter' (sans-serif) for precise, legible financial data and numerical text.
- Minimalist line-based icons for indicator toggles and chart controls to maintain a professional, high-density interface.
- Responsive dashboard layout with a fixed-width watchlist sidebar and a flexible center area for high-resolution charting.
- Fluid, high-performance transitions for price movement updates and smooth opacity fades when toggling technical indicators.
